# 📚 Book API — REST API для управления библиотекой

Это мой пет-проект, созданный для отработки навыков коммерческой backend-разработки.

## 🛠 Стек технологий
*   **Python 3.12**
*   **FastAPI** — веб-фреймворк для создания API.
*   **PostgreSQL** — реляционная база данных.
*   **SQLAlchemy** — ORM для работы с базой данных.
*   **Alembic** — миграции базы данных.
*   **Pydantic** — валидация входящих данных.
*   **JWT (python-jose)** — аутентификация и авторизация.
*   **Passlib (bcrypt)** — хеширование паролей.
*   **Pytest** — автотесты.
*   **Docker (опционально)** — контейнеризация.

## 🚀 Функционал
*   Полный CRUD для книг (создание, чтение, обновление, удаление).
*   Связь «Один ко многим» между авторами и книгами (JOIN).
*   Пагинация и фильтрация по автору.
*   Регистрация и логин пользователей (JWT).
*   Защита эндпоинтов (изменять данные может только авторизованный пользователь).
*   Покрытие базовыми тестами (pytest).

## ⚙️ Как запустить локально
1. Склонируйте репозиторий.
2. Создайте виртуальное окружение и активируйте его:
   `python -m venv venv` и `venv\Scripts\activate`
3. Установите зависимости:
   `pip install -r requirements.txt` (создадим его чуть позже).
4. Настройте подключение к PostgreSQL в файле `database.py`.
5. Примените миграции:
   `alembic upgrade head`
6. Запустите сервер:
   `uvicorn main:app --reload`
7. Откройте документацию: `http://127.0.0.1:8000/docs`

## 🧪 Как запустить тесты
`pytest test_main.py -v`
